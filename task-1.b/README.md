# To-Do List

A simple to-do list app — add, edit, delete, and check off tasks. Built for the Rhombix Technologies Web Development internship (Task 2).

## Features

- Add tasks
- Edit tasks inline
- Delete tasks
- Mark tasks complete
- Tasks persist via `localStorage`

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (no dependencies)

## File Structure

```
todo-app/
├── index.html
├── styles.css
└── script.js
```

## Run Locally

No build step needed — it's a static site.

```bash
git clone https://github.com/thetalhamubarak/todo-app.git
cd todo-app
open index.html
```

Or serve it locally:

```bash
npx serve .
```

## Deploy

Push to GitHub and connect the repo to [Netlify](https://netlify.com), or drag the folder into Netlify's manual deploy.
